Análisis de series temporales financieras usando Python

Objetivos:
- Descargar datos financieros reales.
- Analizar retornos y volatilidad.
- Estudiar correlaciones entre activos.
- Aplicar PCA mediante autovalores y autovectores.
- Simular trayectorias usando Monte Carlo.
- Estimar riesgo mediante Value at Risk.
- Construir un modelo predictivo básico usando regresión lineal.
