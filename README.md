# Proyecto 1 de Física de Finanzas Cuantitativas 

Análisis de series temporales financieras utilizando Python, simulaciones Monte Carlo y aprendizaje automático.

## Objetivos

* Descargar datos financieros reales.
* Analizar retornos y volatilidad.
* Estudiar correlaciones entre activos.
* Aplicar técnicas de álgebra lineal mediante autovalores y autovectores.
* Simular trayectorias futuras usando Monte Carlo.
* Estimar riesgo mediante Value at Risk (VaR).
* Construir un modelo predictivo básico usando regresión lineal.

## Herramientas utilizadas

* Python
* NumPy
* Matplotlib
* yfinance
* scikit-learn

## Análisis realizados

1. Descarga y procesamiento de datos históricos de Bitcoin.
2. Cálculo de retornos diarios.
3. Estimación de media y volatilidad.
4. Simulación Monte Carlo de trayectorias futuras.
5. Estudio del crecimiento de la incertidumbre temporal.
6. Distribución de precios finales simulados.
7. Cálculo de Value at Risk (VaR).
8. Predicción de retornos mediante regresión lineal y evaluación con MSE.

## Resultados principales

* La incertidumbre aumenta con el horizonte temporal de predicción.
* Las simulaciones Monte Carlo permiten explorar escenarios futuros posibles.
* Los retornos diarios presentan baja predictibilidad lineal.
* El modelo de regresión lineal muestra un desempeño limitado, consistente con la naturaleza altamente aleatoria de los mercados financieros.
